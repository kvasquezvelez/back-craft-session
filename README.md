# Backend Craft Session

Backend Node.js para la integración del proyecto.

## Requisitos

- Node.js 20 o superior.
- npm.

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Pruebas

```bash
npm test
```

La configuración privada se administra mediante variables de entorno y no debe subirse al repositorio.
